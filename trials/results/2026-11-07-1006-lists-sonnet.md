## grid

Task: Build a 3 by 3 grid (a list of lists) where the item in row i, column j is i * j (counting from 0). Then change the middle item to 100 and print the grid.

### attempt 1: OK

```cl
fn main() uses io
  var grid: List[List[Int]] = []
  for i in 0 until 3
    var row: List[Int] = []
    for j in 0 until 3
      row = append(list: row, item: i * j)
    end for
    grid = append(list: grid, item: row)
  end for
  grid[1][1] = 100
  print(grid)
end fn main
```
