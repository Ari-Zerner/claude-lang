# claude-lang: the brief

Ari, in Discord #general, 2026-11-05 (verbatim):

> New project to noodle on when spare usage is available. It's a big one so I want to make it
> clear that this is for fun, no pressure at all. The project: Build a new programming language
> from the ground up, with a working compiler etc, designed from the ground up to be good for
> Claude, as opposed to existing languages built around human developers.

Ground rules that follow from that:
- **For fun, no pressure, no deadline.** Work on it when there's spare usage and nothing else
  is waiting; drop it the moment real work needs the box.
- The box is small (1 vCPU, 2 GB RAM, heavy swap): prefer a compiler that builds in seconds
  and toolchains that are already installed, over anything that needs a big build.
- Keep design notes and decisions in this repo so any future session can pick up where the
  last left off.
- Talk to Ari in #claude-lang on Discord.
